# 配置说明

SDK 配置使用**扁平键**。完整键名、默认值与环境变量见 [配置选项](../API参考/04-配置选项.md)。

## 配置方式

优先级从高到低：

1. 运行时 `config.set(key, value)`（进程内）
2. 环境变量 `MIJIA_<扁平键>`（如 `MIJIA_DEFAULT_TIMEOUT`）
3. TOML 配置文件
4. 内置默认值

注意：TOML 嵌套段展平后会带段前缀（`[network] default_timeout` → `NETWORK_DEFAULT_TIMEOUT`），**不会**覆盖默认扁平键。请在顶层写扁平键。

## 准备配置文件

```bash
cp configs/mijiaAPI.toml.template configs/mijiaAPI.toml
```

查找顺序：`configs/mijiaAPI.toml` → 项目根 `config.toml` → `~/.mijia/config.toml` → 内置默认值。

## 常用配置

```toml
# configs/mijiaAPI.toml
DEFAULT_TIMEOUT = 30
MAX_RETRIES = 3
CACHE_TTL = 300
LOG_LEVEL = "INFO"
CREDENTIAL_PATH = "configs/credential.json"
CACHE_DIR = "configs/cache"
```

```python
from pathlib import Path
from mijiaAPI_V2 import create_api_client

api = create_api_client(credential, config_path=Path("configs/mijiaAPI.toml"))
```

环境变量示例：

```bash
export MIJIA_DEFAULT_TIMEOUT=60
export MIJIA_LOG_LEVEL=DEBUG
```

缓存 TTL 当前由代码固定（设备列表 300s、状态 30s、规格约 1 年），不可通过配置修改。

## 凭据路径

默认 `configs/credential.json`（AES-GCM 加密，密钥为同目录 `.credential_key`，或环境变量 `MIJIA_CREDENTIAL_SECRET`）。

- 相对路径：相对项目根目录
- `~/...`：展开为用户目录
- 绝对路径：直接使用

备份时须将 `credential.json` 与 `.credential_key` 成对复制。

## Redis（可选）

安装 `uv sync --extra redis` 后，创建客户端并传入工厂：

```python
import redis
from mijiaAPI_V2 import create_api_client

client = redis.Redis(host="localhost", port=6379, decode_responses=True)
api = create_api_client(credential, redis_client=client)
```

相关键：`REDIS_ENABLED`、`REDIS_HOST`、`REDIS_PORT`、`REDIS_DB`、`REDIS_PASSWORD`、`REDIS_TIMEOUT`、`REDIS_CONNECT_TIMEOUT`。

## 配置检查

```python
from mijiaAPI_V2.factory import create_config_manager

config = create_config_manager()
print(config.get_all())          # 当前生效配置
print(config.get("DEFAULT_TIMEOUT"))
```
