# 配置选项参考

## 配置键对照

代码默认字典（`mijiaAPI_V2/core/config.py`）使用**扁平键名**，例如 `API_BASE_URL`、`DEFAULT_TIMEOUT`。环境变量格式为 `MIJIA_<FLAT_KEY>`，且**只覆盖已存在的默认键**。

TOML 配置文件支持嵌套段，加载时会展平并加段前缀（如 `[network] default_timeout` → `NETWORK_DEFAULT_TIMEOUT`）。**带前缀的键不会覆盖默认扁平键**，也不会被 `MIJIA_*` 环境变量识别。因此：

- **推荐直接使用扁平键名**（TOML 顶层写 `DEFAULT_TIMEOUT = 30`），或
- 环境变量使用 `MIJIA_DEFAULT_TIMEOUT` 这类 `MIJIA_<FLAT_KEY>` 形式

| 常见写法（展平后带前缀） | 实际配置键（扁平） | 环境变量 |
|--------------------------|--------------------|----------|
| `NETWORK_DEFAULT_TIMEOUT` | `DEFAULT_TIMEOUT` | `MIJIA_DEFAULT_TIMEOUT` |
| `NETWORK_MAX_RETRIES` | `MAX_RETRIES` | `MIJIA_MAX_RETRIES` |
| `CACHE_DEVICE_LIST_TTL` 等 | `CACHE_TTL` | `MIJIA_CACHE_TTL` |
| `CREDENTIAL_DEFAULT_PATH` | `CREDENTIAL_PATH` | `MIJIA_CREDENTIAL_PATH` |

以下键**不存在**，请勿使用：`NETWORK_RETRY_DELAY`、`CACHE_HOME_LIST_TTL`、`CACHE_DEVICE_LIST_TTL`、`CACHE_DEVICE_STATE_TTL`、`CACHE_DEVICE_SPEC_TTL`、`REDIS_KEY_PREFIX`、`LOG_FORMAT`、`LOG_FILE`、`LOG_MAX_BYTES`、`LOG_BACKUP_COUNT`、`CREDENTIAL_DEFAULT_PATH`、`CREDENTIAL_AUTO_REFRESH`。

---

## 配置方式

项目支持三种配置方式，优先级从高到低：

1. **环境变量** - 系统环境变量 `MIJIA_<KEY>`
2. **配置文件** - TOML格式配置文件
3. **默认配置** - SDK内置默认值

运行时也可通过 `config.set(key, value)` 修改（进程内生效）。

## 配置文件

### 文件位置

通过 `ConfigManager(config_path=...)` 显式指定配置文件路径。若路径为 `None` 或文件不存在，则只使用默认配置。

### 配置文件格式

推荐使用扁平键（与默认字典一致）：

```toml
# config.toml

API_BASE_URL = "https://api.mijia.tech/app"
DEFAULT_TIMEOUT = 30
MAX_RETRIES = 3
CACHE_TTL = 300
LOG_LEVEL = "INFO"
CREDENTIAL_PATH = "configs/credential.json"
CACHE_DIR = "configs/cache"
REDIS_ENABLED = false
REDIS_HOST = "localhost"
REDIS_PORT = 6379
REDIS_DB = 0
```

嵌套段也支持，但会展平为带段前缀的键（见上文「配置键对照」），通常不会覆盖默认扁平键，不推荐：

```toml
# 不推荐：会展平为 NETWORK_DEFAULT_TIMEOUT 等带前缀键
[network]
default_timeout = 30
```

## API配置

### API_BASE_URL

API基础URL。

- **类型**：`str`
- **默认值**：`"https://api.mijia.tech/app"`
- **环境变量**：`MIJIA_API_BASE_URL`
- **说明**：米家API的基础地址

**示例**：
```toml
API_BASE_URL = "https://api.mijia.tech/app"
```

```bash
# 环境变量
export MIJIA_API_BASE_URL="https://api.mijia.tech/app"
```

```python
# 代码配置
config = ConfigManager()
config.set("API_BASE_URL", "https://api.mijia.tech/app")
```

### LOGIN_URL

登录页地址。

- **类型**：`str`
- **默认值**：`"https://account.xiaomi.com"`
- **环境变量**：`MIJIA_LOGIN_URL`

### SERVICE_LOGIN_URL

服务登录地址。

- **类型**：`str`
- **默认值**：`"https://account.xiaomi.com/pass/serviceLogin"`
- **环境变量**：`MIJIA_SERVICE_LOGIN_URL`

### DEVICE_SPEC_URL

设备规格地址。

- **类型**：`str`
- **默认值**：`"https://miot-spec.org/miot-spec-v2/instance"`
- **环境变量**：`MIJIA_DEVICE_SPEC_URL`

## 网络配置

### DEFAULT_TIMEOUT

默认请求超时时间（秒）。

- **类型**：`int`
- **默认值**：`30`
- **环境变量**：`MIJIA_DEFAULT_TIMEOUT`
- **说明**：HTTP请求的默认超时时间

**示例**：
```toml
DEFAULT_TIMEOUT = 30
```

```python
timeout = config.get("DEFAULT_TIMEOUT")
```

### MAX_RETRIES

最大重试次数。

- **类型**：`int`
- **默认值**：`3`
- **环境变量**：`MIJIA_MAX_RETRIES`
- **说明**：网络请求失败时的最大重试次数

**示例**：
```toml
MAX_RETRIES = 3
```

---

## 缓存配置

### CACHE_TTL

缓存有效期（秒）。

- **类型**：`int`
- **默认值**：`300` (5分钟)
- **环境变量**：`MIJIA_CACHE_TTL`
- **说明**：统一缓存TTL配置键。目前缓存实现中部分TTL为硬编码（如设备列表约 300 秒、设备状态约 30 秒），本键为统一入口

**示例**：
```toml
CACHE_TTL = 300
```

### CACHE_DIR

缓存目录。

- **类型**：`str`
- **默认值**：`"configs/cache"`
- **环境变量**：`MIJIA_CACHE_DIR`

**示例**：
```toml
CACHE_DIR = "configs/cache"
```

## Redis配置

### REDIS_ENABLED

是否启用Redis缓存。

- **类型**：`bool`
- **默认值**：`false`
- **环境变量**：`MIJIA_REDIS_ENABLED`
- **说明**：启用后使用Redis作为分布式缓存

**示例**：
```toml
REDIS_ENABLED = true
```

```bash
export MIJIA_REDIS_ENABLED=true
```

### REDIS_HOST

Redis服务器地址。

- **类型**：`str`
- **默认值**：`"localhost"`
- **环境变量**：`MIJIA_REDIS_HOST`

**示例**：
```toml
REDIS_HOST = "redis.example.com"
```

### REDIS_PORT

Redis服务器端口。

- **类型**：`int`
- **默认值**：`6379`
- **环境变量**：`MIJIA_REDIS_PORT`

**示例**：
```toml
REDIS_PORT = 6379
```

### REDIS_DB

Redis数据库编号。

- **类型**：`int`
- **默认值**：`0`
- **环境变量**：`MIJIA_REDIS_DB`

**示例**：
```toml
REDIS_DB = 0
```

### REDIS_PASSWORD

Redis密码。

- **类型**：`str` 或 `None`
- **默认值**：`None`
- **环境变量**：`MIJIA_REDIS_PASSWORD`

**示例**：
```toml
REDIS_PASSWORD = "your_password"
```

```bash
export MIJIA_REDIS_PASSWORD="your_password"
```

### REDIS_TIMEOUT

Redis操作超时（秒）。

- **类型**：`int`
- **默认值**：`5`
- **环境变量**：`MIJIA_REDIS_TIMEOUT`

### REDIS_CONNECT_TIMEOUT

Redis连接超时（秒）。

- **类型**：`int`
- **默认值**：`5`
- **环境变量**：`MIJIA_REDIS_CONNECT_TIMEOUT`

## 凭据配置

### CREDENTIAL_PATH

凭据文件路径。

- **类型**：`str`
- **默认值**：`"configs/credential.json"`
- **环境变量**：`MIJIA_CREDENTIAL_PATH`

**示例**：
```toml
CREDENTIAL_PATH = "configs/credential.json"
```

落盘默认为 AES-256-GCM。解密密钥优先级：`MIJIA_CREDENTIAL_SECRET` → 同目录 `.credential_key`（自动生成）。备份/迁移时请成对复制凭据与密钥文件。

## 配置管理器

### ConfigManager

配置管理器类，用于读取和管理配置。仅提供 `get` / `set` / `get_all` 三个公开方法。

```python
from mijiaAPI_V2.core.config import ConfigManager

# 创建配置管理器
config = ConfigManager()

# 或指定配置文件
config = ConfigManager(config_path=Path("my_config.toml"))
```

### 读取配置

```python
# 获取配置值
base_url = config.get("API_BASE_URL")
timeout = config.get("DEFAULT_TIMEOUT")

# 获取配置值（带默认值）
max_retries = config.get("MAX_RETRIES", default=3)

# 获取布尔值 / 整数值：统一使用 get()
redis_enabled = config.get("REDIS_ENABLED")
redis_port = config.get("REDIS_PORT")

# 获取全部配置
all_config = config.get_all()
```

### 设置配置

```python
# 设置配置值
config.set("API_BASE_URL", "https://api.example.com")
config.set("DEFAULT_TIMEOUT", 60)
config.set("REDIS_ENABLED", True)
```

### 配置优先级

```python
# 1. 环境变量（最高优先级）
# export MIJIA_REDIS_ENABLED=false

# 2. 配置文件
# REDIS_ENABLED = false

# 3. 默认配置（最低优先级）
```

运行时 `config.set(...)` 仅修改当前进程内存中的配置，不影响后续新实例的默认值。

## 使用示例

### 基本配置

```python
from pathlib import Path
from mijiaAPI_V2 import create_api_client
from mijiaAPI_V2.core.config import ConfigManager

# 创建配置
config = ConfigManager(config_path=Path("config.toml"))

# 修改配置
config.set("DEFAULT_TIMEOUT", 60)
config.set("CACHE_TTL", 600)

api = create_api_client(credential)
```

## 配置验证

```python
from mijiaAPI_V2.core.config import ConfigManager

def validate_config(config: ConfigManager) -> bool:
    """验证配置"""
    # 检查必需配置
    if not config.get("API_BASE_URL"):
        print("错误：缺少API_BASE_URL配置")
        return False
    
    # 检查Redis配置
    if config.get("REDIS_ENABLED"):
        if not config.get("REDIS_HOST"):
            print("错误：启用Redis但未配置REDIS_HOST")
            return False
    
    # 检查超时配置
    timeout = config.get("DEFAULT_TIMEOUT")
    if timeout < 1 or timeout > 300:
        print(f"警告：超时时间 {timeout} 不在推荐范围(1-300)")
    
    return True

# 使用
config = ConfigManager()
if validate_config(config):
    print("配置验证通过")
else:
    print("配置验证失败")
```

## 最佳实践

### 1. 使用环境变量管理敏感信息

```bash
export MIJIA_REDIS_PASSWORD="your_secret_password"
```

### 2. 不同环境使用不同配置

```python
import os
from pathlib import Path

# 根据环境选择配置文件
env = os.getenv("ENV", "development")
config_file = Path(f"configs/{env}.toml")

config = ConfigManager(config_path=config_file)
```

### 3. 配置文件版本控制

```gitignore
# .gitignore
config.toml          # 不提交本地配置
production.toml      # 不提交生产配置
*.local.toml         # 不提交本地配置

# 提交模板配置
config.example.toml  # 提交配置模板
```

### 4. 配置文档化

```toml
# config.example.toml
# 这是配置文件模板，复制为 config.toml 并修改

# API基础URL，通常不需要修改
API_BASE_URL = "https://api.mijia.tech/app"

# 请求超时时间（秒），建议30-60
DEFAULT_TIMEOUT = 30

# 最大重试次数，建议3-5
MAX_RETRIES = 3
```
