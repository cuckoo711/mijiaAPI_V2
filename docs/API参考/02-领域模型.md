## Credential（凭据）

用户认证凭据，是整个系统的核心对象。

### 定义

```python
class Credential(BaseModel):
    """用户凭据
    
    包含用户认证所需的所有信息。
    """
    user_id: str          # 用户ID
    service_token: str    # 服务Token
    ssecurity: str        # 安全密钥
    pass_token: Optional[str] = ""  # 通行Token，用于刷新凭据
    c_user_id: str        # Cookie用户ID
    device_id: str        # 设备ID
    user_agent: str       # User-Agent
    expires_at: datetime  # 过期时间
```

### 属性说明

#### user_id
- **类型**：`str`
- **说明**：用户的唯一标识符
- **用途**：
  - 缓存命名空间隔离
  - 日志追踪
  - 多用户场景的用户区分

#### service_token
- **类型**：`str`
- **说明**：服务访问令牌
- **用途**：API请求的认证凭证
- **注意**：敏感信息，需要安全存储

#### ssecurity
- **类型**：`str`
- **说明**：安全密钥
- **用途**：
  - 请求数据加密
  - 签名生成
- **注意**：敏感信息，需要安全存储

#### pass_token
- **类型**：`Optional[str]`
- **说明**：通行Token，用于刷新凭据

#### c_user_id
- **类型**：`str`
- **说明**：Cookie用户ID

#### device_id
- **类型**：`str`
- **说明**：设备ID

#### user_agent
- **类型**：`str`
- **说明**：User-Agent

#### expires_at
- **类型**：`datetime`
- **说明**：凭据过期时间
- **用途**：判断凭据是否过期

### 方法

#### is_expired()

检查凭据是否已过期。

```python
def is_expired(self) -> bool:
    """检查凭据是否已过期"""
    return datetime.now() >= self.expires_at
```

#### is_valid()

检查凭据是否有效（未过期且 `service_token` 非空）。

```python
def is_valid(self) -> bool:
    return not self.is_expired() and bool(self.service_token)
```

#### expires_in()

返回剩余有效时间（秒），已过期时返回 `0`。

```python
def expires_in(self) -> int
```

#### to_dict() / from_dict()

```python
def to_dict(self) -> dict[str, Any]

@classmethod
def from_dict(cls, data: dict[str, Any]) -> "Credential"
```

**使用示例**：
```python
if credential.is_expired():
    print("凭据已过期，需要刷新")
    credential = auth_service.refresh_credential(credential)
else:
    print(f"凭据有效，剩余 {credential.expires_in()} 秒")
```

### 序列化

```python
# 推荐：使用内置方法
credential_dict = credential.to_dict()
credential = Credential.from_dict(credential_dict)

# 或使用 Pydantic 接口
credential_dict = credential.model_dump()
credential_json = credential.model_dump_json()
credential = Credential.model_validate(credential_dict)
credential = Credential.model_validate_json(credential_json)
```

### 存储建议

```python
# 不推荐：明文存储
with open("credential.json", "w") as f:
    f.write(credential.model_dump_json())

# 推荐：使用凭据存储服务
from mijiaAPI_V2.infrastructure.credential_store import FileCredentialStore

store = FileCredentialStore()
store.save(credential)  # 自动处理路径和格式
```

## Home（家庭）

表示一个米家智能家居的家庭。

### 定义

```python
class Home(BaseModel):
    """家庭实体"""
    id: str               # 家庭ID
    name: str             # 家庭名称
    uid: str              # 所有者用户ID
    rooms: List[Dict]     # 房间列表
```

### 属性说明

#### id
- **类型**：`str`
- **说明**：家庭的唯一标识符
- **用途**：获取家庭下的设备、智能等

#### name
- **类型**：`str`
- **说明**：家庭名称（用户自定义）
- **示例**：`"我的家"`, `"公司"`

#### uid
- **类型**：`str`
- **说明**：家庭所有者的用户ID
- **用途**：权限判断

#### rooms
- **类型**：`List[Dict]`
- **说明**：房间列表
- **结构**：
```python
{
    "id": "room_id",
    "name": "客厅",
    "icon": "icon_url"
}
```

### 使用示例

```python
# 获取家庭列表
homes = api.get_homes()

# 遍历家庭
for home in homes:
    print(f"家庭: {home.name}")
    print(f"  ID: {home.id}")
    print(f"  所有者: {home.uid}")
    print(f"  房间数: {len(home.rooms)}")
    
    # 遍历房间
    for room in home.rooms:
        print(f"    - {room['name']}")
```

## Device（设备）

表示一个智能设备。

### 定义

```python
class Device(BaseModel):
    """设备实体"""
    did: str                    # 设备ID
    name: str                   # 设备名称
    model: str                  # 设备型号
    home_id: str                # 所属家庭ID
    room_id: Optional[str]      # 所属房间ID
    status: DeviceStatus        # 在线状态（DeviceStatus枚举）
    parent_id: Optional[str]    # 父设备ID（网关设备）
    parent_model: Optional[str] # 父设备型号
```

### 属性说明

#### did
- **类型**：`str`
- **说明**：设备的唯一标识符
- **用途**：控制设备、获取设备状态

#### name
- **类型**：`str`
- **说明**：设备名称（用户自定义）
- **示例**：`"客厅灯"`, `"卧室空调"`

#### model
- **类型**：`str`
- **说明**：设备型号
- **示例**：`"yeelink.light.lamp4"`, `"xiaomi.aircondition.v1"`
- **用途**：
  - 获取设备规格
  - 判断设备类型
  - 确定支持的功能

#### home_id
- **类型**：`str`
- **说明**：设备所属的家庭ID

#### room_id
- **类型**：`Optional[str]`
- **说明**：设备所属的房间ID
- **注意**：可能为None（未分配房间）

#### status
- **类型**：`DeviceStatus`
- **说明**：设备在线状态（`DeviceStatus` 枚举，见下文「枚举类型」）
- **取值**：
  - `DeviceStatus.ONLINE` (`"online"`): 在线
  - `DeviceStatus.OFFLINE` (`"offline"`): 离线
  - `DeviceStatus.UNKNOWN` (`"unknown"`): 未知（默认值）

#### parent_id / parent_model
- **类型**：`Optional[str]`
- **说明**：父设备信息（用于子设备）
- **场景**：网关下的子设备（如温湿度传感器）

### 方法

#### is_online()

检查设备是否在线。

```python
def is_online(self) -> bool:
    return self.status == DeviceStatus.ONLINE
```

### 使用示例

```python
# 获取设备列表
devices = api.get_devices(home_id="123456")

# 筛选在线设备
online_devices = [d for d in devices if d.is_online()]
print(f"在线设备: {len(online_devices)}/{len(devices)}")

# 按型号分组
from collections import defaultdict
by_model = defaultdict(list)
for device in devices:
    by_model[device.model].append(device)

for model, devices in by_model.items():
    print(f"{model}: {len(devices)}台")

# 查找特定设备
light = next((d for d in devices if "light" in d.model), None)
if light:
    print(f"找到灯: {light.name}")
```

表示一个智能。

### 定义

```python
class Scene(BaseModel):
    """智能实体"""
    scene_id: str             # 智能ID
    name: str                 # 智能名称
    home_id: str              # 所属家庭ID
    icon: Optional[str]       # 智能图标
    owner_uid: Optional[str]  # 家庭拥有者用户ID
```

### 属性说明

#### scene_id
- **类型**：`str`
- **说明**：智能的唯一标识符
- **用途**：执行智能

#### name
- **类型**：`str`
- **说明**：智能名称（用户自定义）
- **示例**：`"回家模式"`, `"离家模式"`, `"睡眠模式"`

#### home_id
- **类型**：`str`
- **说明**：智能所属的家庭ID

#### owner_uid
- **类型**：`Optional[str]`
- **说明**：家庭拥有者用户ID。共享家庭执行智能时可能需要传入

### 使用示例

```python
# 获取智能列表
scenes = api.get_scenes(home_id="123456")

# 显示所有智能
for scene in scenes:
    print(f"智能: {scene.name} (ID: {scene.scene_id})")

# 执行特定智能
morning_scene = next((s for s in scenes if "早晨" in s.name), None)
if morning_scene:
    success = api.execute_scene(
        scene_id=morning_scene.scene_id,
        home_id=morning_scene.home_id,
    )
    print(f"执行早晨智能: {'成功' if success else '失败'}")
```

## DeviceSpec（设备规格）

设备的规格信息，定义设备支持的属性和操作。定义在 `mijiaAPI_V2/repositories/interfaces.py` 中。

### 定义

```python
class DeviceSpec(BaseModel):
    """设备规格"""
    model: str                          # 设备型号
    name: str                           # 设备名称
    properties: List[DeviceProperty]    # 属性列表
    actions: List[DeviceAction]         # 操作列表
```

### DeviceProperty（设备属性）

定义在 `mijiaAPI_V2/domain/models.py`。

```python
class DeviceProperty(BaseModel):
    """设备属性"""
    siid: int                          # 服务ID
    piid: int                          # 属性ID
    name: str                          # 属性名称
    type: PropertyType                 # 属性类型
    access: PropertyAccess             # 访问权限
    value: Optional[Any]               # 属性值
    value_range: Optional[List[Any]]   # 值范围
    value_list: Optional[List[Any]]    # 枚举值列表
```

**方法**：
- `is_readable() -> bool`: 是否可读
- `is_writable() -> bool`: 是否可写
- `validate_value(value) -> bool`: 验证值是否有效

### DeviceAction（设备操作）

```python
class DeviceAction(BaseModel):
    """设备操作"""
    siid: int                          # 服务ID
    aiid: int                          # 操作ID
    name: str                          # 操作名称
    parameters: List[ActionParameter]  # 参数列表
```

### ActionParameter（操作参数）

```python
class ActionParameter(BaseModel):
    """操作参数"""
    name: str                          # 参数名称
    piid: Optional[int]                # 参数对应的属性ID
    type: PropertyType                 # 参数类型
    required: bool                     # 是否必需
    value_range: Optional[List[Any]]   # 值范围
    value_list: Optional[List[Any]]    # 枚举值列表
```

### 使用示例

```python
# 获取设备规格
spec = api.get_device_spec(model="yeelink.light.lamp4")
if spec is None:
    print("规格不存在")
else:
    # 查看属性
    for prop in spec.properties:
        access = prop.access.value
        print(f"属性: {prop.name} (siid={prop.siid}, piid={prop.piid})")
        print(f"  类型: {prop.type.value}, 权限: {access}")

        if prop.value_range:
            print(f"  范围: {prop.value_range}")
        if prop.value_list:
            print(f"  可选值: {prop.value_list}")

    # 查看操作
    for action in spec.actions:
        print(f"操作: {action.name} (siid={action.siid}, aiid={action.aiid})")
```

## 数据验证

所有模型都使用 Pydantic 进行自动验证。

### 验证示例

```python
from datetime import datetime
from pydantic import ValidationError

# 正确的数据
try:
    credential = Credential(
        user_id="123456",
        service_token="token_xxx",
        ssecurity="secret_xxx",
        c_user_id="c_user_xxx",
        device_id="device_xxx",
        user_agent="app/1.0",
        expires_at=datetime.now(),
    )
    print("验证通过")
except ValidationError as e:
    print(f"验证失败: {e}")

# 错误的数据（缺少必需字段）
try:
    credential = Credential(
        user_id="123456",
        # 缺少 service_token
        ssecurity="secret_xxx",
        c_user_id="c_user_xxx",
        device_id="device_xxx",
        user_agent="app/1.0",
        expires_at=datetime.now(),
    )
except ValidationError as e:
    print(f"验证失败: {e}")
    # 输出: Field required [type=missing, input_value=...]

# 错误的数据类型
try:
    credential = Credential(
        user_id="123456",
        service_token="token_xxx",
        ssecurity="secret_xxx",
        c_user_id="c_user_xxx",
        device_id="device_xxx",
        user_agent="app/1.0",
        expires_at="not_a_datetime"  # 应该是 datetime
    )
except ValidationError as e:
    print(f"验证失败: {e}")
```

## 模型转换

### 字典转换

```python
# 模型 → 字典
device_dict = device.model_dump()

# 字典 → 模型
device = Device.model_validate(device_dict)

# 排除某些字段
device_dict = device.model_dump(exclude={"parent_model"})

# 只包含某些字段
device_dict = device.model_dump(include={"did", "name", "model"})
```

### JSON转换

```python
# 模型 → JSON字符串
device_json = device.model_dump_json()

# JSON字符串 → 模型
device = Device.model_validate_json(device_json)

# 美化输出
device_json = device.model_dump_json(indent=2)
```

### 批量转换

```python
# 模型列表 → 字典列表
devices_dict = [d.model_dump() for d in devices]

# 字典列表 → 模型列表
devices = [Device.model_validate(d) for d in devices_dict]
```

## 最佳实践

### 1. 使用类型提示

```python
from typing import List

def online_names(devices: List[Device]) -> List[str]:
    """返回在线设备名称"""
    return [d.name for d in devices if d.is_online()]
```

### 2. 验证外部数据

```python
# 从API获取的数据
api_response = {"did": "123", "name": "灯", "model": "xxx"}

# 使用模型验证
try:
    device = Device.model_validate(api_response)
    # 数据有效，可以安全使用
except ValidationError as e:
    # 数据无效，记录错误
    logger.error(f"设备数据无效: {e}")
```

### 3. 序列化配置

```python
# 自定义序列化
device_dict = device.model_dump(
    exclude_none=True,      # 排除None值
    exclude_unset=True,     # 排除未设置的字段
)
```
