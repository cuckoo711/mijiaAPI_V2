# 测试指南

使用 `pytest`（及 `pytest-cov`、`pytest-mock`、`pytest-asyncio`、`hypothesis`）。

## 运行测试

```bash
uv run pytest                          # 全部
uv run pytest tests/unit/              # 单元
uv run pytest tests/integration/       # 集成
uv run pytest tests/unit/test_api_client.py::test_name

uv run pytest -v                       # 详细
uv run pytest --cov=mijiaAPI_V2 --cov-report=term-missing
uv run pytest --cov=mijiaAPI_V2 --cov-report=html   # 生成 htmlcov/
```

Docker 生命周期验证见 `tests/docker/` 与 [部署说明](../../deploy/README.md)。

## 目录结构

| 目录 | 内容 |
|------|------|
| `tests/unit/` | 服务、仓储、HTTP、凭据等单元测试 |
| `tests/integration/` | 工厂组装、日志等集成路径 |
| `tests/property/` | Hypothesis 属性测试 |
| `tests/performance/` | 性能相关 |
| `tests/docker/` | 隔离卷冒烟 |

命名：`test_*.py`；用例 `test_*`，fixture 用描述性名称。

## 编写要点

- 单元测试对仓储/HTTP 使用 Mock，不打真实米家接口
- 集成测试走 `create_api_client` / 工厂组装，与生产路径一致
- 控制类逻辑注意 `ExecutionUnknownError`：不得断言自动重发
- 异步用 `pytest-asyncio`
