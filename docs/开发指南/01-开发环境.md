# 开发环境搭建

支持 macOS、Linux、Windows，需要 Python 3.9+。管理台开发还需 Node.js 和 npm。

## 安装 uv

macOS / Linux：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
# macOS 也可使用 Homebrew
brew install uv
```

Windows PowerShell：

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

安装后运行 `uv --version` 检查。

## 克隆项目与安装依赖

```bash
git clone https://github.com/cuckoo711/mijiaAPI_V2.git
cd mijiaAPI_V2
uv sync --extra dev
```

也可从 `https://gitee.com/cuckoo711/mijiaAPI.git` 克隆，目录名为 `mijiaAPI`。`uv sync` 会创建 `.venv` 并以可编辑模式安装项目；不需要开发工具时可省略 `--extra dev`。

| 可选依赖 | 安装命令 |
|------|------|
| Redis | `uv sync --extra redis` |
| CLI 工具 | `uv sync --extra cli` |
| 文档生成 | `uv sync --extra docs` |
| 全部依赖 | `uv sync --all-extras` |

## 运行命令与 IDE

使用 `uv run` 无需手动激活虚拟环境：

```bash
uv run python script.py
uv run pytest
uv run mypy mijiaAPI_V2 server
```

也可手动激活：

```bash
# macOS / Linux
source .venv/bin/activate
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

VS Code 在“Python: Select Interpreter”中选择项目 `.venv`；PyCharm 在项目 Python Interpreter 中选择同一环境。Windows 解释器路径为 `.venv\Scripts\python.exe`，macOS / Linux 为 `.venv/bin/python`。测试运行器选择 pytest，格式化使用 Black。

## 项目结构

```text
mijiaAPI_V2/   # Python SDK
server/        # FastAPI
web/           # Vue 管理台
configs/       # 默认数据与配置模板
deploy/        # Docker、systemd、打包与运维脚本
docs/          # 文档
examples/      # 使用示例
tests/         # 测试
```

## 常用检查

```bash
uv run pytest tests/ --no-cov
uv run black --check mijiaAPI_V2 server
uv run isort --check-only mijiaAPI_V2 server
uv run flake8 mijiaAPI_V2 server
uv run mypy mijiaAPI_V2 server
uv run pylint mijiaAPI_V2 server
```

安装 Make 后也可使用以下目标；`make help` 查看列表。

| 命令 | 用途 |
|------|------|
| `make install` / `make dev` | 安装项目依赖 |
| `make test` | 运行测试，不生成覆盖率 |
| `make test-cov` | 运行测试并生成覆盖率 |
| `make format` | Black 格式化与 isort 导入排序 |
| `make lint` | flake8 检查 |
| `make type-check` | mypy 检查 |
| `make clean` | 清理缓存与临时文件 |

提交前运行相关测试和代码检查，仅暂存本次修改。编码与提交规范见[代码规范](02-代码规范.md)，测试编写及覆盖率命令见[测试指南](03-测试指南.md)。
