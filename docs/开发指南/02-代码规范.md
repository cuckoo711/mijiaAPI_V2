# 代码规范

## 语言

- 文档、注释、提交说明：简体中文
- 标识符、代码、API 命名：英文（PEP 8）

## Python 约定

- 格式化 / 导入排序：`black`、`isort`；检查：`flake8`、`mypy`、`pylint`
- 必须类型提示；公开 API 使用 Google 风格 docstring
- 异常使用 `domain.exceptions` 中的类型，避免裸 `except:`；必要时 `raise ... from`
- 敏感信息（token、密钥）不得写入代码或日志

```bash
uv run black mijiaAPI_V2 server
uv run isort mijiaAPI_V2 server
uv run mypy mijiaAPI_V2
uv run flake8 mijiaAPI_V2 server
```

## 提交说明

```
<type>(<scope>): <说明>

type: feat | fix | docs | refactor | test | chore | ci | build
scope: 可选，如 api / server / android / release
```

示例：`fix(server): keep CSRF cookie on failed login`

## 测试

测试放在 `tests/`，命名 `test_*.py`；先跑 `uv run pytest`。详见 [测试指南](03-测试指南.md)。
