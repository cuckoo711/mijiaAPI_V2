# 项目概览

米家 API SDK（`mijiaAPI_V2`）提供扫码认证、家庭与设备查询、属性读写和场景执行。API Server 在 SDK 之上提供 HTTP API 和网页管理台。

## 组成

| 目录 | 职责 |
|------|------|
| `mijiaAPI_V2/` | Python SDK：客户端、领域模型、业务服务、仓储和基础设施 |
| `server/` | FastAPI 服务、管理员与 API Key 鉴权、资源授权、SQLite 存储和审计 |
| `web/` | Vue3 管理台，构建后由 API Server 托管 |
| `configs/` | 配置模板与默认运行数据目录 |
| `deploy/` | 部署配置、打包和维护脚本 |
| `examples/` | SDK 使用示例 |
| `tests/` | 单元与集成测试 |

## SDK 结构

```text
mijiaAPI_V2/
├── api_client.py       # MijiaAPI / AsyncMijiaAPI
├── factory.py          # 组件组装与客户端工厂
├── core/               # 配置与日志
├── domain/             # Credential、Device、Home、Scene 等模型及异常
├── infrastructure/     # HTTP、加密、凭据存储、缓存
├── repositories/       # 家庭、设备、场景与规格的数据访问
└── services/           # 认证、设备、场景与统计业务
```

- `Credential` 独立于客户端，可保存、加载和刷新；每个用户使用独立客户端与缓存命名空间。
- `MijiaAPI` 提供同步接口；`AsyncMijiaAPI` 通过 `asyncio.to_thread` 调用同步业务服务。
- SDK 默认使用内存和文件缓存，可选 Redis；API Server 使用 SQLite 保存管理数据与资源快照。
- 服务层通过仓储接口访问数据，工厂负责组装依赖。各层职责见[分层架构](02-分层架构.md)。

## 技术栈

| 用途 | 组件 |
|------|------|
| 模型校验 | Pydantic |
| HTTP 请求与重试 | httpx、tenacity |
| 缓存 | cachetools、可选 Redis |
| 协议加密与凭据存储 | PyCryptodome、cryptography |
| 扫码登录二维码 | qrcode、Pillow |
| API Server | FastAPI、Uvicorn、SQLite |
| 管理台 | Vue3、TypeScript、Vite、Element Plus |

依赖版本见 [`pyproject.toml`](../../pyproject.toml) 和 [`web/package.json`](../../web/package.json)。
